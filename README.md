# روبوت إعراب القرآن — أوفلاين (مشروع أندرويد جاهز)

تطبيق أندرويد يعرض **روبوت إعراب القرآن الأوفلاين** (نفس محرك القواعد وقاعدة
البيانات المرجعية من `The Quranic Arabic Corpus`) داخل تطبيق حقيقي، بدون أي
اتصال بالإنترنت إطلاقًا — لاحظ أن `AndroidManifest.xml` لا يطلب صلاحية
`INTERNET` عمدًا.

كل بيانات إعراب كلمات القرآن الكاملة (~139 ألف مقطع صرفي) مضمّنة مسبقًا داخل
`app/src/main/assets/index.html` كملف واحد ذاتي الاكتفاء، ويعرضه التطبيق عبر
`WebView` محلي فقط.

## ⚠️ توضيح مهم

هذا **ليس نموذج ذكاء اصطناعي توليدي (LLM)**. هو محرك قواعد + قاعدة بيانات
مرجعية موثّقة، يُخرج نفس الإعراب دائمًا لنفس الكلمة، ولا "يخترع" تحليلًا غير
موجود في البيانات. هذا مقصود لتفادي الأخطاء (hallucination) عند التعامل مع
النص القرآني. راجع `LLM_SYSTEM_PROMPT_AR.txt` في مشروع الـ API الأصلي إن
رغبت لاحقًا بربط نموذج لغوي حقيقي فوق هذه الطبقة.

## كيف تحصل على ملف APK

### الطريقة 1 — عبر GitHub Actions (لا تحتاج تثبيت أي شيء عندك)

1. ارفع محتوى هذا المجلد كما هو إلى مستودع جديد على GitHub.
2. بمجرد الرفع (push) إلى فرع `main` أو `master`، سيعمل ملف
   `.github/workflows/build-apk.yml` تلقائيًا ويبني التطبيق.
3. من تبويب **Actions** في المستودع، افتح آخر تشغيل (run) ناجح، وحمّل
   الملف المرفق (Artifact) باسم `quran-irab-robot-debug-apk` — بداخله
   `app-debug.apk` الجاهز للتثبيت.
4. يمكنك أيضًا تشغيل البناء يدويًا في أي وقت من تبويب Actions عبر
   "Run workflow" (بفضل `workflow_dispatch`).

> هذا يبني نسخة **Debug** (قابلة للتثبيت والتجربة مباشرة). لنشره على متجر
> Google Play لاحقًا، ستحتاج بناء نسخة Release موقّعة بمفتاحك الخاص.

### الطريقة 2 — عبر Android Studio على جهازك

1. افتح المجلد كمشروع Android Studio (Open an existing project).
2. اضغط Run، أو من القائمة: Build → Build Bundle(s) / APK(s) → Build APK(s).
3. ستجد الملف الناتج في: `app/build/outputs/apk/debug/app-debug.apk`.

## هيكل المشروع

| الملف/المجلد | الوظيفة |
|---|---|
| `app/src/main/assets/index.html` | التطبيق الأوفلاين الكامل (واجهة + بيانات الإعراب) |
| `app/src/main/java/.../MainActivity.java` | نشاط واحد يعرض الملف أعلاه داخل WebView محلي |
| `app/src/main/AndroidManifest.xml` | إعدادات التطبيق — بلا صلاحية إنترنت عمدًا |
| `.github/workflows/build-apk.yml` | بناء تلقائي لملف APK عبر GitHub Actions |
